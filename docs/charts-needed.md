# Sizing charts needed

Everything in the categories and styles is an estimate. These are the charts that replace it.
Send them in any form: screenshots, PDFs, a spreadsheet, or typed numbers.

## For every model, for every size

Please give the measurement as the maker defines it, and say which.

- Seat tube length, and whether it is center-to-top or center-to-center
- Top tube length (actual) or effective top tube length
- Head tube length
- Head tube angle and seat tube angle (some makers change them by size)
- Chainstay length
- BB drop, or BB height (and the tire size it was measured with)
- Fork axle-to-crown and rake (offset), and the tire size they assume
- Wheel and tire size
- Stack and reach
- Wheelbase
- Standover height
- Trail
- Crank length
- Rear spacing and BB shell width

## For every model, once

- The rider height range for each size
- Mountain bikes: fork travel, and sag if given
- A note on anything unusual (offset rear end, suspension corrected geometry, etc.)
